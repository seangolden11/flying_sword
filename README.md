# Simultaneous Shot

여러 공을 따로 조준한 뒤 한 번에 발사하는 Unity 2D 물리 POC입니다. Stage 1~6의 공 개수는 각각 1~6개이며, 시작 화면 또는 Esc로 연 스테이지 선택 화면에서 스테이지를 바꿀 수 있습니다.

## 실행

- Unity에서는 프로젝트 루트를 Unity 6000.3.22f1로 열고 `Assets/Scenes/SampleScene.unity`를 연 다음 Play를 누릅니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 공 좌클릭 후 드래그 | 당긴 방향의 반대로 조준합니다. 점선이 예상 이동 및 반사 경로를 보여줍니다. |
| 좌클릭 놓기 | 공을 제자리에 두고 해당 공의 조준을 저장합니다. |
| 같은 공 다시 드래그 | 해당 공의 조준을 바꿉니다. |
| 공 우클릭 | 해당 공의 조준을 취소합니다. |
| Space | 조준 중에는 모든 공을 동시에 발사합니다. 실행 중에는 공을 즉시 멈추고 다음 턴으로 넘어갑니다. |
| R | 현재 스테이지를 처음 배치로 되돌립니다. |
| Esc | 플레이를 일시 정지하고 스테이지 선택 화면을 엽니다. 한 번 더 누르면 재개합니다. |

실행 중에는 공을 조준할 수 없습니다. 조준하지 않은 공도 다른 공에 맞으면 움직입니다. 모든 공이 멈추면 마지막 위치에서 새 조준을 시작합니다. 저장된 조준이 없는 상태에서 Space를 누르면 Planning을 유지합니다.

## 주인공과 적

흰색 마름모는 맵 중앙의 주인공(HP 10)이며 분홍색 사각형은 적(시작 HP는 스테이지 번호 × 3)입니다. 바닥은 17×17칸이며 각 칸의 폭은 0.8 유닛입니다. 발사 후 모든 공이 멈추면 기존 적은 빈 칸을 따라 주인공 옆까지 가는 최단 경로에서 상하좌우로 한 칸 이동합니다. 이미 인접했거나 경로가 없으면 대기합니다. 새 적은 주인공에게 상하좌우로 두 칸 이내인 위치를 제외한 빈 칸에 무작위로 스테이지 번호의 5배만큼 생성되어 다음 턴부터 움직입니다. 빈 칸이 부족하면 가능한 수만큼 생성됩니다. 공은 연속적인 물리 공간에서 움직이며 적과 충돌할 때마다 체력을 1 깎고 튕깁니다. 체력 0인 적은 사라집니다. R 또는 스테이지 선택으로 턴과 적을 초기화할 수 있습니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `Assets/Scenes/SampleScene.unity` | 플레이 씬과 조정용 오브젝트 `Shot Arena` |
| `Assets/Scripts/StageManager.cs` | 대칭 초기 배치, 공 생성과 교체, 네 벽과 경기장 생성 |
| `Assets/Scripts/BallController.cs` | 공의 Rigidbody2D, 원형 콜라이더, 조준 벡터와 점선 궤적 |
| `Assets/Scripts/AimController.cs` | 마우스 조준과 Space/R 입력, 당김 거리의 속도 변환 |
| `Assets/Scripts/LaunchManager.cs` | 한 물리 프레임에서 전체 공의 초기 속도 설정 |
| `Assets/Scripts/GameStateManager.cs` | Planning과 Execution 전환, 전체 정지 판정 |
| `Assets/Scripts/TurnActors.cs` | 바닥 그리드, 무작위 생성과 턴 이동, 체력 표시 |
| `Assets/Scripts/EnemyTarget.cs` | 적의 충돌체, 체력과 제거 |
| `Assets/Scripts/UIManager.cs` | 독립 스테이지 선택 화면과 플레이 중 체력 표시 |
| `ProjectSettings/Physics2DSettings.asset` | 중력과 충돌 반발 임계 속도 |

## 물리 파라미터

씬의 `Shot Arena`를 선택하면 Inspector에서 다음 값을 조정할 수 있습니다.

| 컴포넌트 | 설정 | 기본값 |
| --- | --- | --- |
| Stage Manager | 공 반지름 / 질량 | 0.36 유닛 / 1 |
| Stage Manager | 선형 감쇠 / 마찰 | 0.85 / 0.02 |
| Stage Manager | 공-공 및 공-벽 반발 계수 | 0.9 |
| Stage Manager | 벽·공·적 충돌 후 속도 배율 | 1.25배 |
| Physics 2D 프로젝트 설정 | 최대 이동 속도 및 충돌 가속 직후 속도 상한 | 100 유닛/초 |

발사 후 처음 5초는 초기 속도 상한을 유지합니다. 다음 5초 동안 상한이 선형으로 낮아져 발사 10초 시점에 0이 되면 남은 공이 모두 정지하고 턴이 종료됩니다. 턴 종료, 스테이지 선택 또는 초기화 시 원래 상한으로 돌아갑니다.
| Aim Controller | 최대 당김 거리 / 초기 속도 상한 | 1.5 유닛 / 48 유닛/초 |
| Aim Controller | 조준 최소 당김 거리 | 0.06 유닛 |
| Game State Manager | 정지 속도 / 판정 유지 시간 | 0.085 유닛/초 / 0.16초 |

중력은 Physics 2D 설정에서 (0, 0)이며 공의 Gravity Scale도 0입니다. 공은 연속 충돌 감지를 사용합니다. 초기 배치를 바꾸려면 `StageManager.Layouts`의 좌표를 수정하세요.
