# Flying Sword

검을 타고 WASD로 이동하며 검의 발사·합체·회수로 싸우는 Unity 2D 횡스크롤 POC입니다.

## 실행

Unity 6000.3.22f1에서 Assets/Scenes/Title.unity를 열고 Play를 누릅니다. 타이틀에서 검 전투·메트로배니아·보스전을 선택합니다. 각 스테이지는 독립된 씬이며, 새로 진입하면 체력과 장비가 초기화됩니다. 기존 SampleScene은 타이틀로 이동하는 호환용 씬입니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 검을 타고 이동 |
| 좌클릭 / 길게 누르기 | 커서 방향 발사 / 연속 발사 |
| 우클릭 | 커서 반경 1 유닛 안에서 내 검 수동 회수 · 적의 떨어진 검 획득 |
| 1 길게 누르기 | 회전 속도를 높이며 검 합체 |
| 3 | 커서 근처 꽂힌 검으로 교차 참격 |
| 4 길게 누르기 | 검막 |
| 5 | 커서 궤적을 따르는 이기어검 전환 |
| Tab | 비활성화 |
| Esc | 일시 정지·재개, 메뉴에서 타이틀 복귀 |

R 회수, 기본 궤도의 자동 요격, 미니맵은 사용하지 않습니다. 발사한 검은 비행 중 근처 탄막을 추적하고, 목적지에 도달하면 중력으로 떨어집니다. 비행·낙하 중 적과 탄막에 충돌하며, 지형에 닿으면 진행 방향으로 꽂힙니다. 꽂힌 검은 3초 후 자동 회수됩니다. 합체 검의 공격력과 방어 횟수는 구성한 검 수에 비례하며, 회수 후 원래 종류로 분해됩니다.

## 장비

가방은 큰 카드 두 구역으로 구성되어 있습니다. 클릭 또는 드래그로 장착·보관하고, 모두 장착·모두 보관 버튼도 사용할 수 있습니다. 가방을 열면 게임이 멈추고 진행 중인 합체를 정리합니다.

| 종류 | 시작 지급 | 효과 |
| --- | --- | --- |
| 기본 검 | 20자루 장착 | 피해 1 |
| 질풍검 | 2자루 보관 | 자루마다 전체 검 속도 +15%, 중첩 |
| 귀환검 | 2자루 보관 | 자루마다 회수 속도 +25%, 중첩 |
| 낙인검 | 2자루 보관 | 명중한 적을 락온 대상으로 지정 |

질풍검 2자루는 검 속도 1.30배, 귀환검 2자루는 회수 보너스 1.50배입니다. 둘을 함께 장착하면 최종 회수 속도는 1.95배입니다. 장착한 검은 비행·낙하·합체 중에도 보너스를 유지합니다. 낙인 대상에게는 검이 곡선 궤적으로 날아가며 트레일을 남깁니다. 대상이 죽거나 새 대상을 지정하면 락온이 바뀝니다.

## 전투와 지형

플레이어 체력은 10, 피격 피해는 1이며 0.6초 동안 연속 피해를 받지 않습니다. 적은 체력 30으로 3마리씩 가까이 모여 등장합니다. 시작 및 전멸 후 대기 시간은 5초입니다. 일반 공격은 0.55초 간격이고 특공은 5초 주기로 10발을 발사합니다. 탄환은 속도 10.2로 발사 순간의 플레이어 위치를 향해 직진합니다.

적은 10 유닛 안에서 지형에 시야가 가리지 않을 때 플레이어를 인지하고 공격합니다. 플레이어의 검에 피해를 받으면 즉시 인지하고 반격을 준비하며, 이후에는 거리나 시야 차단과 관계없이 죽을 때까지 공격을 계속합니다. 탄환은 계속 지형에 막힙니다. 시야로만 인지한 적은 범위 밖이나 지형 뒤로 벗어나면 공격을 멈춥니다. 새로 등장한 적은 피격 인지 상태를 물려받지 않습니다. 체력·특공 게이지·인지 상태는 각 적 머리 위에 표시됩니다. 피격 인지 상태는 ‘피격 인지 · 교전 중’으로 표시됩니다. 체력이 줄면 몸 색과 중심부 크기도 변합니다. 인식 원과 시야 선은 EnemySystem의 Show Detection Range로 켜고 끕니다.

메트로배니아 씬은 발판·기둥·상하 통로가 있는 탐험 실험장입니다. 플레이어와 검·적 탄환은 지형에 막힙니다. 회수 중인 검은 지형을 통과합니다. 잠금 해제나 방 연결 진행은 아직 구현하지 않았습니다.

| 위치 | 편집 대상 |
| --- | --- |

| Assets/Game/Prefabs/GameUI.prefab | Canvas HUD·메뉴·가방 배치 |
| Assets/Game/Prefabs/SwordSlot.prefab | 검 카드 크기·아이콘·설명 |
| Assets/Game/Prefabs/Player.prefab | 플레이어와 탑승 검 |
| Assets/Game/Prefabs/Sword.prefab | 발사 검 외형과 트레일 |
| Assets/Game/Prefabs/Enemy.prefab | 적 외형과 머리 위 UI |
| Assets/Game/Prefabs/EnemyBullet.prefab | 적 탄환 |
| Assets/Game/Prefabs/HitEffect.prefab | 충돌 효과 |
| Assets/Game/Prefabs/TerrainBlock.prefab | 지형 블록 공통 외형·충돌 |
| Assets/Game/Equipment/*.asset | 검 이름·색·공격력·보너스·시작 수량 |

UI와 지형은 저장된 에셋을 에디터에서 편집합니다. UI는 CanvasScaler와 앵커로 화면 크기에 대응하고, 가방은 자동 열 배치와 세로 스크롤을 사용합니다. 새 지형을 추가하면 Stage Geometry의 Surfaces 목록에도 해당 BoxCollider2D를 등록하세요.

StageManager는 초기화와 업데이트 순서만 담당합니다. Player는 이동·체력, Enemies는 스폰·공격·탄환, Equipment는 장착·보너스, Swords는 검 상태·충돌·진형, UI는 화면과 입력을 담당합니다. SwordSystem의 비행과 진형 코드는 각각 Flight와 Formations 파일에 있습니다. 탄환·검·적·충돌 효과는 사용이 끝난 오브젝트를 재사용하며, 장비 보너스는 구성이 바뀔 때 갱신합니다.

## 검증과 초기 에셋 재생성

Unity 메뉴 Flying Sword > Validate Project는 두 스테이지의 장비 보너스, 낙하·자동 회수, 합체 분해, 적 스폰·풀링, 탄환 직진, 가방 드롭·일시 정지를 검사합니다. 결과는 Console과 Logs/RefactorChecks.txt에 남습니다. 실행 전 편집 중인 씬을 저장하세요. 검증은 테스트 중 생성한 오브젝트를 저장하지 않고 타이틀로 돌아옵니다.

Flying Sword > Build Project Assets는 초기 에셋을 다시 만드는 개발 도구입니다. 씬과 프리팹·장비 값을 초기 구성으로 덮어쓰므로 평소 편집에는 사용하지 마세요. 게임 실행 시에는 이 도구를 사용하지 않습니다.

## 보스전

타이틀의 보스전을 선택하면 기본 검 1자루만 지급받고 전용 경기장에서 크기 3배, 체력 50인 보스 한 마리가 즉시 등장합니다. 보스는 플레이어처럼 검을 타고 한 자루의 전투용 검을 두른 검사 모습이며, 기본 공격으로 플레이어를 유도 추적하는 검 한 자루를 발사합니다. 검이 돌아오기 전에는 추가 발사하지 않으며 연사 특공은 사용하지 않습니다. 유도 검은 초당 7.5 유닛, 초당 최대 110도로 방향을 바꿉니다. 명중·방어·지형 충돌 또는 비행 2.5초 경과 시 비활성화되어 떨어지며, 비활성화 이후 3초가 지나면 보스에게 돌아옵니다. 낙하·회수 중에는 피해를 주지 않습니다. 회수 완료 후 1.1초 동안 준비한 다음 다시 발사합니다. 회전 중인 검·발사한 검·낙하 중인 검과 검막으로 막을 수 있고, 방어에 사용한 검은 기존 반동·낙하 처리를 따릅니다. 일반 적의 탄환은 직진을 유지합니다. 보스는 거리와 지형의 시야 차단에 관계없이 플레이어를 인지합니다. 일반 적의 시야 범위는 10 유닛을 유지합니다. 보스 체력은 화면 상단 중앙의 긴 붉은 체력바로 표시하며 보스 이름과 체력바만 보여주며 체력 수치와 패턴·상태 설명 문구는 표시하지 않습니다. 피해 구간은 잠시 남았다가 줄어들고, 처치 후 체력바가 2초 뒤 사라집니다. 보스 크기에 맞춰 검의 타격 범위도 확대됩니다. 처치 후 자동 재등장하지 않으며 Esc로 타이틀에 돌아갈 수 있습니다.

검사 보스와 유도 검 프리팹은 Assets/Resources/Enemies에 저장합니다. SwordBossAssets는 처음 스크립트가 반영될 때 프리팹을 생성하며 열린 씬은 수정하지 않습니다. 실행 중이면 편집 모드로 돌아온 뒤 생성합니다.

## 현재 회수 및 가방 규칙

가방은 삭제하지 않고 비활성화했습니다. HUD 버튼과 Tab으로 열 수 없습니다. 내 검의 자동 회수는 비활성화했습니다. 우클릭으로 커서 반경 1 유닛 안에서 낙하 중이거나 꽂힌 내 검을 수동 회수할 수 있습니다. 대신 커서 반경 1 유닛 안에서 낙하 중이거나 지형에 꽂힌 적의 검을 회수해 한 번 발사할 수 있습니다. 획득한 검은 다음 좌클릭 발사에 우선 사용되며 합체되지 않습니다. 빼앗은 검은 발사 후 명중·방어·지형 충돌·목적지 도착 시 떨어지거나 기다리지 않고 즉시 원래 주인에게 돌아갑니다. 빼앗긴 동안 보스는 검을 추가 생성하거나 발사하지 않습니다.

빼앗은 검은 원래 적 검의 형태·색·크기·트레일을 유지합니다. 획득 순간부터 3초 동안만 보유할 수 있으며, 시간이 지날수록 점점 강하게 떨립니다. 그 안에 발사하지 않으면 즉시 원래 적에게 돌아갑니다. 발사했다면 공격 종료 시 바로 적에게 돌아가는 규칙을 유지합니다.

## 검 외형과 잔상

칼날은 일정한 폭의 양날과 짧은 끝부분, 금속 명암으로 표현합니다. 가드와 손잡이는 별도 스프라이트이며 SVG 원본도 Assets/Game/Art에 보관합니다. 트레일은 칼끝이 아니라 Visual의 손잡이 방향 로컬 위치 (0, 0.50, 0)에서 생성합니다. 발사·회수·탑승 이동 때 짧은 잔상을 남기고, 궤도에 복귀하거나 검이 비활성화되면 잔상 생성을 멈춥니다.

## 적의 검 탈취

플레이어 고유 검이 지형에 꽂히면 인지 상태인 적은 반경 14 유닛 안에서 가장 가까운 검의 탈취를 시도합니다. 적에게서 빨간 원이 초당 10 유닛으로 검을 향해 이동합니다. 원이 도착하기 전에 우클릭으로 회수하거나 교차 참격으로 검을 움직이면 취소됩니다. 도착하면 적이 검을 빼앗아 초당 15 유닛으로 자신의 위치로 가져갑니다. 가져온 뒤 0.8초간 준비하고 발사 순간 플레이어 위치를 향해 속도 16으로 발사합니다. 플레이어 검에 막히거나, 지형에 닿거나, 목적지에 도착하면 다시 떨어집니다. 빼앗긴 검은 플레이어의 발사와 장비 보너스에서 제외됩니다. 커서 반경 1 유닛 안에서 우클릭으로 되찾거나 적을 처치해 떨어뜨릴 수 있습니다. 적마다 한 번에 하나의 검만 노리며, 실패 후 2초 뒤 다시 시도합니다.

## 보스 거대 검 범위 공격

보스는 손에 든 검의 상태와 독립적으로 1.1초마다 범위 공격을 5번 연속 예고합니다. 다섯 번째 공격까지 모두 종료되면 10초 동안 범위 공격을 쉬고 다음 5연격을 시작합니다. 최초 대기 시간은 2초이며, 예고와 비행을 합쳐 보스당 최대 3개가 동시에 진행됩니다. 앞선 검이 화면 밖으로 사라지기 전에도 다음 공격이 시작됩니다. 플레이어 위치를 기준으로 폭 2.2 유닛의 빨간 띠를 1.2초간 예고하고, 가로·세로·대각선 방향 중 하나로 크기 8배의 검이 화면 밖에서 날아와 반대편 화면 밖으로 사라집니다. 예고 위치는 고정되며 플레이어를 뒤따라 움직이지 않습니다. 거대 검은 속도 32로 지형을 관통하며 지나가는 동안 범위 안에 있는 플레이어에게 1 피해를 한 번 줍니다. 예고만으로는 피해가 발생하지 않습니다. 범위 공격 중에도 기본 검의 발사·회수는 계속되며, 기본 검이 빼앗긴 상태에서도 범위 공격은 발생합니다. 보스 처치 시 진행 중인 범위 공격도 사라집니다.

## 검 대기·발사·회수 연출

평상시 검은 원을 돌지 않고 플레이어 등 뒤에서 가로로 누워 조준 방향을 향합니다. 여러 자루는 가로 자세를 유지한 채 높낮이를 달리해 나란히 배치됩니다. 작은 부유 움직임과 이동 지연이 있으며 대기 중에는 트레일을 만들지 않습니다. 좌클릭 발사 전 약 0.16초 동안 목표 방향으로 돌아서 살짝 당겨졌다가 발사합니다. 회수 시 목표 위치를 조금 지나친 뒤 정착하며, 이동 중에도 정착이 끝나도록 처리합니다. 보스도 등 뒤에서 검을 가로로 대기시킵니다. 검막·합체·이기어검 기술의 별도 진형은 유지합니다.

## 첫 보스 검 보상

검사 보스를 처치하면 소지하던 검이 떨어집니다. 전리품 검 근처에서 우클릭을 2초 유지해 획득을 완료하면 영구 소유하며, 한 번 사용 후 반환하거나 3초 뒤 사라지지 않습니다. 사용 후에는 다른 내 검처럼 떨어지고 우클릭으로 다시 회수합니다. 검 형태는 유지하고, 영구 획득 완료 시 칼날과 트레일은 플레이어의 청록색으로 바뀝니다. 소유 여부는 현재 스토리 진행에만 속합니다. 타이틀에서 새로 시작하면 미획득 상태이며 이전 플레이에서 얻은 검을 미리 지급하지 않습니다. 다시 도전하면 스테이지 진입 당시 소유 상태로 복원됩니다. 같은 스토리의 다음 구간으로 진행할 때만 획득한 검을 이어서 사용합니다. 보스 처치 전에 빼앗아 들고 있던 검은 전리품으로 떨어지며, 우클릭 유지 과정을 거쳐야 영구 보상으로 확정됩니다.

전리품 획득은 우클릭을 시작할 때 검을 선택하고, 이후 누르고 있는 동안 카메라가 그 검을 향해 점점 가까워집니다. 2초를 채우기 전 버튼을 놓으면 진행이 초기화되고 카메라는 원래 시점으로 돌아갑니다. 획득 완료 시에만 현재 스토리의 소유 상태가 변경됩니다. 다른 내 검의 회수와 살아 있는 적의 검 탈취에는 이 연출을 적용하지 않습니다.
