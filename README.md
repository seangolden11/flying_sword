# Flying Sword

중앙에 고정된 플레이어가 검을 발사·설치·회수하며 살아남는 Unity 2D 프로토타입입니다. 100×100 유한 맵에서 검 3개로 시작하며, 화면 가장자리에서 근접·원거리 적이 계속 등장합니다. 카메라는 중앙 전투 구역을 고정해서 비춥니다.

## 실행

Unity Hub에서 프로젝트 폴더를 Unity 6000.3.22f1로 열고, `Assets/Scenes/SampleScene.unity`를 연 다음 Play를 누릅니다.

시작 씬의 `Shot Arena` → `Turn Actors` → `Initial Sword Count`는 3입니다. 테스트를 위해 Inspector에서 바꿀 수 있으며 최소 1개입니다. HUD는 공전 중 사용 가능한 검 / 실제 지급된 총 보유 검을 표시합니다. R키 초기화·재시작 입력은 제거했습니다. 최초 시작에 필요한 내부 초기화는 유지합니다.

## 전투와 성장

- 기본 검은 발사·회수 중 명중한 적에게 기본 피해 1을 줍니다. 레벨과 관계없이 근접 적 HP는 2, 원거리 적 HP는 1입니다. 일반 투척 명중 후 튕겨 설치되며, 회수는 관통하고 한 번의 회수에서 같은 적을 한 번만 타격합니다. 일반 공전·설치는 피해가 없고, 해금된 검막을 켠 동안만 공전 공격이 가능합니다.
- 발사된 검은 반경 2 안, 진행 방향과 최초 조준 방향에서 각각 ±20도 안에 있는 가장 가까운 적을 약하게 유도합니다. 회전은 초당 60도로 제한하며 탄환 요격이 우선입니다. 원래 목표까지의 비행 거리 이상으로 적을 쫓지 않고 설치됩니다. Inspector의 `Weak enemy homing`에서 거리·각도·회전 속도를 조절할 수 있습니다.
- 투척·유도·요격·튕김으로 이동하는 검은 카메라 안으로 제한됩니다. 검 전체와 화면 흔들림을 위한 여백을 두며, 경계에 닿으면 화면 안에 설치됩니다. 맵과 적 이동 범위는 이 제한과 별개입니다.
- 수동 투척은 클릭 지점보다 0.8만큼 더 비행하여 적 바로 앞에 떨어지는 상황을 줄입니다(`Launch Overshoot`로 조절). 화면 경계 제한은 그대로 적용합니다. 투척·회수의 적 명중 판정은 검끝뿐 아니라 뒤로 이어진 검날 길이와 폭을 포함합니다. 유도 강도와 추가 추적 시간은 늘리지 않습니다.
- 살아남은 적은 넉백됩니다. 원거리 적은 사거리까지 접근한 뒤 단발 발사 → 이동 → 대기를 반복합니다. 기존 고정 무적 적과 20연사는 제거했습니다.
- 적 머리 위에 HP 바가 표시됩니다. 피해를 받으면 현재 체력 비율에 맞춰 오른쪽부터 줄어들고, 처치되면 함께 사라집니다.
- 처치 즉시 경험치 1을 얻습니다. 요구 경험치는 3 → 5 → 7 → 9…으로 레벨업마다 2씩 증가하며 초과 경험치는 유지됩니다. 레벨업 시 게임 시간이 멈추고, 유효한 보상 중 동일 확률로 중복 없이 3개를 추첨합니다. 여러 레벨이 동시에 오르면 레벨마다 한 번씩 순서대로 선택하고, 모두 선택한 후 전투가 재개됩니다. 검 자동 지급은 없으며, 발사·설치된 무기를 강제로 회수하지 않습니다.
- HP는 10, 접촉·탄환 피해는 1, 피격 후 무적 시간은 2초입니다. HP가 0이 되면 전투가 멈추고 게임 오버를 표시합니다. 재시작 키나 버튼은 없습니다.
- 스폰 간격(2초), 원거리 적 비율(35%), 근접/원거리 이동 속도(1.1/0.8), 원거리 사거리(7), 공격 주기(2.5초), 발사 후 이동 시간(0.9초), 탄속(3.4), 넉백 속도/시간(6/0.2초)은 Inspector의 `Survival test tuning`에서 조절하는 테스트용 값입니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 커서 쪽으로 검을 발사합니다. 누르고 있으면 연속 발사합니다. |
| 우클릭 | 커서 주변 지면에 꽂힌 검을 회수합니다. 누르고 있는 동안 범위 안의 검을 계속 회수합니다. |
| 1 | 검 합체 — 초기 잠금 |
| 2 | 자동 요격 — 초기 잠금 |
| 3 | 교차 참격 — 초기 잠금 |
| 4 | 검막 — 초기 잠금 |
| 5 | 이기어검 — 초기 잠금 |

지면에 설치된 검은 설치 시점부터 5초 후 자동 회수를 시작합니다. 스킬 잠금과 별개로 적용되며, 우클릭으로 먼저 회수할 수 있습니다. 다시 설치되면 5초를 새로 셉니다. 자동 회수 중에도 같은 회수 피해·관통 규칙이 적용됩니다. 보상 선택 중에는 이 타이머도 멈춥니다.

화면 왼쪽 위에는 조작과 무기 수, 아래에는 HP·적 수·레벨·경험치가 표시됩니다. 오른쪽에는 보유 무기 요약을 표시하며 보상 대상 선택 화면에서 전체 목록을 볼 수 있습니다. 1·2·4번 스킬은 레벨업 해금 보상으로 획득하고, 3·5번은 계속 잠깁니다. 이미 획득한 해금·패시브 보상은 풀에서 제외합니다.

보상은 기본 검 +1, 삭제, 복사, 공격력 +1, 공통 자동 회수 -1초, 공통 호밍 강화, 신규 무기 6종, 스킬 해금 3종, 패시브 2종입니다. 각 화면에서 리롤은 한 번만 가능하며 이전 보상이 다시 등장할 수 있습니다. 리롤은 보상을 소비하지 않고 다음 화면에서 다시 한 번 사용할 수 있습니다. `Reward Choice Count`로 카드 수를 바꿀 수 있습니다. 선택 화면은 uGUI + InputSystemUIInputModule로 구성해 Input System 전용 설정에서도 마우스로 조작합니다.

삭제·복사·공격력은 보상 카드를 누른 후 보유 무기 목록에서 대상을 확정합니다. 뒤로 가기로 카드를 다시 고를 수 있으며 리롤 사용 횟수는 복구되지 않습니다. 공전·비행·설치·회수·요격 중인 무기도 대상으로 선택할 수 있습니다. 마지막 무기는 삭제할 수 없습니다. 복사본은 공격력 강화를 유지하고 공통 호밍을 적용받으며, 설치 시간·타격 기록·탄환 예약 등 실행 상태를 새로 시작하여 공전 대열에 합류합니다.

공격력 +1은 선택 무기의 투척·회수 피해에 적용됩니다. 호밍 강화는 모든 현재·미래 무기에 단계당 감지 거리 +0.25, 감지 각도 +5도, 회전 속도 +10도/초를 적용하며 최대 3단계입니다. 무기 대상 선택 없이 카드 선택 즉시 적용되고, 3단계에 도달하면 보상 풀에서 제외합니다. 새 무기·복사본·시너지·일시 합체와 분해된 무기도 동일한 공통 단계를 적용받습니다.

자동 회수 강화는 모든 현재·미래 무기에 5→4→3→2→1초로 적용합니다. 이미 설치된 무기의 경과 시간을 유지하고, 새 제한을 넘었다면 전투 재개 시 회수를 시작합니다. 1초에 도달하면 해당 보상을 추첨 풀에서 제외합니다.

## 신규 무기·시너지·스킬

| 무기 | 투척 특수 효과 |
| --- | --- |
| 조각검 | 명중 시 독립 공격 분신 2개 소환. 타격 후에도 유지되며 원본 회수 시작 시 소멸 |
| 쓰레기통 | 처음 맞힌 적과 다른 적에게 추가 호밍 1회. 대상이 없으면 튕겨 설치 |
| 테이블 | 느린 비행, 강한 넉백 |
| 모니터 | 전기 광역 폭발. 직접 명중한 적에게는 같은 폭발의 피해를 중복 적용하지 않음 |
| 펜싱칼 | 한 번의 투척에서 여러 적 관통, 같은 적은 한 번만 타격 |
| 세탁기 | 설치 순간 주변 적만 바깥쪽으로 강하게 넉백. 추가 피해·무기 이동 없음 |

회수 중에는 조각 생성·추가 호밍·전기 폭발이 발동하지 않습니다. 세탁기 넉백은 무기의 설치 위치·상태·자동 회수 타이머를 변경하지 않습니다.

- 쓰레기통 + 테이블 + 모니터 → **전격 작업대**: 추가 호밍·강한 넉백·전기 폭발.
- 기본 검 + 조각검 + 펜싱칼 → **파편 성검**: 관통·명중 시 분신 2개 소환. 분신은 독립 공격하고 원본 회수 시 소멸하며 재귀 소환하지 않습니다.
- 재료가 모이면 종류별로 하나씩 즉시 소모하고 상위 무기를 공전 상태로 생성합니다. 공격력 강화 단계가 낮은 개체, 동률이면 획득 ID가 작은 개체를 우선 소모합니다. 재료의 강화는 승계하지 않습니다.
- 1번 일시 합체 안의 구성품은 자동 시너지 재료에서 제외하고, 복귀 후 분해되는 즉시 다시 검사합니다.
- 1번은 공전 무기를 일시 합체합니다. 공격력은 합산하고 고유 능력은 종류당 한 번 결합하며 호밍은 공통 강화 단계를 사용합니다. 구성품을 개별 강화·복사·삭제할 수 있고, 분해 시 원래 ID·종류·강화를 보존합니다. 화면 안에 보이도록 합체 **시각 크기만** 최대 3.5배로 제한하며 공격력·보유량은 제한하지 않습니다.
- 4번 검막은 무기별 현재 공격력·넉백을 사용하고, 같은 적에 대한 무기별 재타격 간격(테스트 기본 0.5초)을 둡니다. 기존 탄환 차단도 유지합니다.

## 패시브·난이도

- 피격 반격: 보상 획득 이후 실제 접촉 피해를 받으면 그 적에게 피해 1과 넉백. 내부 쿨타임 10초. 무적 중 접촉이나 탄환 피해에는 발동하지 않습니다.
- 처치 회복: 획득 이후부터 10킬마다 HP 1 회복, 최대 10. 투척·회수·조각·폭발·반격 처치를 모두 포함하며 이전 킬은 소급하지 않습니다.
- 적 체력은 레벨에 따라 증가하지 않습니다. 근접 HP 2, 원거리 HP 1로 고정하며 이미 등장한 적의 현재 HP도 레벨업으로 바뀌지 않습니다.
- 스폰 간격은 `max(최소 간격, 기본 간격 - (레벨 - 1) × 감소량)`입니다. 테스트 기본값은 2초, 레벨당 0.06초 감소, 최소 0.25초이며 Inspector에서 조절합니다. 적 비율은 유지합니다.

## 아트와 테스트 수치

실제 이미지 생성 도구로 만든 PNG 24종을 `Assets/Resources/Art`에 연결했습니다. 무기 9종, 아이콘 12종, 효과 3종이며 Point 필터·PPU 64·최대 텍스처 64·무압축·알파 사용 설정입니다. 생성·수정 프롬프트는 같은 폴더의 `generation-prompts.json`에 있습니다. 원본 PNG는 보존하며 실제 Sprite bounds로 월드 표시 크기를 정규화합니다. 일반 무기는 최대 길이 1.5, 분신은 0.75, 효과는 지정된 범위 크기를 사용합니다.

`Weapon Test Tuning`에서 종류별 기본 피해·비행 속도·넉백, 연쇄 사거리·제한 시간, 분신 피해·속도·탐색 범위·타격 간격·표시 크기, 폭발 범위·피해, 세탁기 넉백 범위·속도·시간, 검막 타격 간격을 조절합니다. 이 수치들은 최종 밸런스가 아닙니다.

## 검증

Play Mode에서 `Flying Sword → Run Survival Smoke Check`를 실행하면 기존 전투 회귀와 성장 외에 신규 무기·회수 효과 분리·재귀 방지·시너지·일시 합체 보존·스킬 해금·패시브·난이도·아트 로드·uGUI 콜백을 검사합니다. 배치 진입점은 `-executeMethod SurvivalSmokeCheck.RunBatch`이며 `-quit` 없이 실행합니다. 도메인 리로드 후 테스트를 이어가고 완료 시 종료하도록 구성했습니다.

C# 컴파일은 Unity 6000.3.22f1 라이브러리 참조 빌드로 확인했습니다. 배치 실행은 초기화 단계에서 종료되었으나, 열린 Editor에 연결하여 Play 실행과 기본 검의 표시 크기 수정 후 화면을 확인했습니다. 전체 통합 스모크 체크와 모든 무기·보상 UI의 실제 플레이 검증은 아직 미완료입니다.

분신은 원본 무기당 정확히 2개를 유지하며, 대상이 없으면 대기하다 주변 적을 다시 탐색합니다. 타격 후 반복 공격하며 기본 타격 간격은 0.6초, 피해 1, 탐색 범위 3.5, 이동 속도 12입니다. 원본 회수(수동·자동·요격 후 복귀) 또는 삭제 시 정리됩니다. 이 규칙은 조각검·파편 성검·조각검 능력을 포함한 1번 일시 합체 모두에 적용됩니다. 세탁기 넉백 파동은 반경 2.8, 속도 20, 시간 0.35초의 Inspector 테스트 기본값이며, 세탁기를 포함한 일시 합체에도 적용됩니다.

일시 합체 및 시너지 무기(전격 작업대·파편 성검)는 기존 계산된 투척 속도의 2배로 발사됩니다. 일반 무기와 회수·튕김 속도는 그대로입니다. 시너지 기본 프로필은 유지하여 전격 작업대는 10→20, 파편 성검은 18→36으로 적용되며 일시 합체에서도 배율은 한 번만 적용합니다.

한 번에 등장하는 마릿수는 레벨이 아니라 생존 시간에 따라 증가합니다. 테스트 기본값은 0~59초 1마리, 60~119초 2마리, 120~179초 3마리입니다. Inspector의 Initial Spawn Count(1), Spawn Count Growth Interval(60초), Additional Enemies Per Time Step(1)로 조절합니다. 보상 선택·일시정지·게임오버 중에는 생존 시간이 누적되지 않습니다. 기존 레벨별 스폰 간격 감소, 적 HP와 근접·원거리 비율은 유지합니다.
