# Flying Sword

검을 타고 횡스크롤 경기장을 이동하며, 주위를 도는 검을 발사하고 회수해 적의 탄막에 대응하는 Unity 2D POC입니다. 카메라는 플레이어를 가로로 따라갑니다. 시작 시 검 20개가 플레이어 주위를 돕니다. 검은 발사 중 직선으로 날아가고, 비행이 끝나면 중력으로 떨어져 바닥에 꽂힙니다. 떨어지는 검도 적에게 피해를 주고 탄막을 요격합니다. 적에 맞은 검은 충돌면에서 짧게 튕긴 뒤 중력에 따라 떨어집니다. 같은 검이 다시 피해를 주려면 적의 충돌 범위를 벗어났다 다시 닿아야 합니다. 적의 시작 체력은 10이며 검에 맞을 때마다 1씩 줄어듭니다. 적은 한 번에 한 명만 등장하며, 쓰러지면 1초 뒤 같은 위치에 새 적이 나타납니다. 바닥에 꽂힌 검은 회수, 자동 요격, 교차 참격에 사용할 수 있습니다.

## 실행

Unity Hub에서 프로젝트 폴더를 Unity 6000.3.22f1로 열고, `Assets/Scenes/SampleScene.unity`를 연 다음 Play를 누릅니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 검을 타고 위 / 왼쪽 / 아래 / 오른쪽으로 이동합니다. |
| 좌클릭 | 커서 쪽으로 검을 발사합니다. 누르고 있으면 연속 발사합니다. |
| 우클릭 | 커서 주변 지면에 꽂힌 검을 회수합니다. 누르고 있는 동안 범위 안의 검을 계속 회수합니다. |
| 1 길게 누르기 | 주위를 도는 검을 합칩니다. 키를 놓으면 합쳐진 검을 사용할 수 있습니다. |
| 2 | 지면에 꽂힌 검의 자동 요격을 켜거나 끕니다. |
| 3 | 커서 주변 지면에 꽂힌 검을 반대편으로 보내 교차 참격을 발동합니다. |
| 4 길게 누르기 | 주위를 도는 검으로 검막을 펼칩니다. |
| 5 | 검이 커서의 이동 경로를 따라가는 이기어검을 켜거나 끕니다. |
| R | 경기장을 초기화합니다. |

화면 왼쪽 위에는 조작 안내와 발사 가능한 검 개수가 표시됩니다. 화면 아래에는 적의 다음 탄막까지 남은 시간이 표시됩니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `Assets/Scenes/SampleScene.unity` | 플레이 씬과 경기장 오브젝트 `Shot Arena` |
| `Assets/Scripts/StageManager.cs` | 카메라와 경기장 초기화 |
| `Assets/Scripts/TurnActors.cs` | 검의 상태와 기술, 적의 발사체, 충돌 처리 |
| `Assets/Scripts/UIManager.cs` | 조작 안내, 사용 가능한 검 개수, 적 탄막 게이지 |
